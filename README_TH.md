# ปลาศาลาหุม — เว็บไซต์หลายไฟล์ HTML

## เวอร์ชัน GitHub + ฐานข้อมูลกลาง (22 ต.ค. 2026)

เริ่มที่ **[DEPLOY_GITHUB_DATABASE_TH.md](DEPLOY_GITHUB_DATABASE_TH.md)** สำหรับวิธีสร้าง Supabase เพิ่มสมาชิก และเปิด GitHub Pages

ค่าเริ่มต้นยังเป็น `enabled: false` เพื่อทดลองเดโมได้ทันที ฐานข้อมูลกลางจะทำงานหลังตั้งค่า `assets/js/database-config.js` และรัน SQL ตามคู่มือ ยังไม่มีโปรเจกต์/ลิงก์ที่เผยแพร่ไว้ให้แล้ว

ด้านล่างเป็นวิธีใช้โหมดเดโมเดิม ข้อความ “ไม่ต้อง API Key” หมายถึงเฉพาะโหมด local เท่านั้น โหมดฐานข้อมูลต้องใช้ Publishable key + สมาชิกที่ล็อกอินจริง และมีแถบ “ฐานข้อมูลกลาง” บนหน้าเว็บ

การสลับบทบาทในแอปยังเป็นการสาธิตสำหรับทีมที่ไว้ใจกัน ไม่ใช่ระบบกำหนดสิทธิ์ฟาร์ม/ผู้ซื้อจริง ดูขอบเขตความปลอดภัยในคู่มือ deployment ก่อนแชร์

**เปิดครั้งแรก: แตก ZIP → เปิด Server จากโฟลเดอร์เว็บ → เปิด index.html → เลือกบทบาท → เริ่ม Scenario**

เว็บภาษาไทย 19 หน้า HTML5 + CSS3 + Vanilla JavaScript ไม่มี Build Step ไม่ต้อง npm ไม่ต้อง API Key ทุกภาพและไฟล์ที่จำเป็นอยู่ในชุด

## คอมพิวเตอร์

1. แตก spark-fish-multi-html.zip แล้วเปิด Terminal ในโฟลเดอร์ spark-fish-multi-html ที่มี index.html
2. ถ้าเลือกวิธี Python ต้องมี Python 3 ในเครื่อง แล้วรันตามระบบ:

macOS:

    python3 -m http.server 8000 --bind 127.0.0.1

Windows:

    py -m http.server 8000 --bind 127.0.0.1

3. เปิด http://localhost:8000/index.html
4. กด “เลือกบทบาททดลอง” หรือเริ่ม “ทดลองขายปกติ”, “ทดลองพบความเสี่ยง”, “ทดลองข้อมูลไม่ครบ”
5. อ่านลำดับคลิกและค่าที่ควรเห็นใน DEMO_GUIDE_TH.md

ใช้ VS Code Live Server หรือ Static Server อื่นแทน Python ได้ ถ้าพอร์ต8000ใช้ไม่ได้ เปลี่ยนคำสั่งและ URL เป็น8001 กด Ctrl+C เพื่อหยุด

## โทรศัพท์ใน Wi-Fi เดียวกัน

หยุด Server เดิม แล้วรัน:

macOS:

    python3 -m http.server 8000 --bind 0.0.0.0

Windows:

    py -m http.server 8000 --bind 0.0.0.0

หา IPv4 ของคอม: Windows ใช้ ipconfig; macOS: System Settings → Wi-Fi → Details → TCP/IP
เปิด http://IP-ของคอม:8000/index.html ในมือถือ เช่น http://192.168.1.20:8000/index.html
หากเข้าไม่ได้ ตรวจ Guest Wi-Fi/การแยกอุปกรณ์ และอนุญาต Python ผ่าน Firewall เฉพาะเครือข่ายส่วนตัว ไม่ต้องเปิดพอร์ต Router

**ข้อมูลไม่ Sync ข้ามเครื่อง**: Browser และ Origin แต่ละชุดมี localStorage แยกกัน localhost, 127.0.0.1 และ IP ของคอมเป็นคนละ Origin สาธิตสลับบทบาทใน Browser เดียวกันเป็นหลัก

## ของที่อยู่ในชุด

- HTML หลัก 19 ไฟล์ มี heading, section, form และโครงสร้างของตนเอง
- assets/css: tokens, base, components, layout และ pages
- assets/js: config, demo-data, utils, calculations, risk-engine, store, domain, app-shell
- assets/js/pages: Logic แยกแต่ละหน้าชื่อเดียวกับ HTML
- assets/images: ภาพ WebP 5 ภาพ พร้อมที่มาใน assets/IMAGE_CREDITS.md
- tests/test-runner.html: ทดสอบกฎธุรกรรมใน Browser โดยไม่เปลี่ยนข้อมูลที่ทดลอง
- tests/responsive-check.html: ตรวจหน้าจอ360/390/768/1280/1440px
- tests/run-node.js และ tests/check-files.py: เครื่องมือทดสอบเพิ่มเติม ไม่จำเป็นต่อการเปิดเว็บ
- EDIT_GUIDE_TH.md, DEMO_GUIDE_TH.md, TEST_REPORT_TH.md: คู่มือแก้ไข เดโม และผลตรวจ

## ขอบเขต

ทำงานครบตั้งแต่ค่าน้ำ → ผลสองแกน → งานดูแล → แผนจับ/ข้อเสนอ → จัดสรรและยืนยัน → ชั่งจริงสร้างล็อต → ส่ง/รับมอบ → เงินสุทธิ
ราคา น้ำหนัก และทุกบัญชีเป็นสมมติ ภาพสร้างประกอบ ไม่อ้างว่าเป็นภาพสถานที่จริง ไม่มีการรับรองหรือเชื่อม PTT/NECTEC

ไม่มี Login จริงหรือระบบสิทธิ Server การซ่อนหน้าตามบทบาทใน Frontend ไม่ใช่การควบคุมสิทธิที่ปลอดภัยสำหรับใช้จริง
ไม่มี LINE/SMS/Email ธนาคาร เซนเซอร์ หรืออุปกรณ์จริง ทุกสถานะรับ/จ่ายเงินคือเดโม

กฎไม่มีเกณฑ์ค่าน้ำสัมบูรณ์ที่ผ่านผู้เชี่ยวชาญ ไม่วินิจฉัยโรค ไม่สั่งยา ไม่สั่งจับอัตโนมัติจากตัวเลขเดียว
เงินสุทธิยังไม่หักค่าอาหาร ลูกพันธุ์ และแรงงานเลี้ยง จึงไม่ใช่กำไรสุทธิ

State อยู่ใน key spark-fish-demo-v1 มี schemaVersion/revision/updatedAt ไม่ seed ใหม่เมื่อเปลี่ยนหน้า Refresh หรือบทบาท
Seed ใหม่เฉพาะครั้งแรกหรือยืนยัน Reset/Scenario มีส่งออก JSON สำรองในหน้า guide แต่รุ่นนี้ยังไม่มีปุ่มนำเข้า JSON
Demo Clock หยุดที่เวลาเริ่มชุด เพื่อไม่ให้เดโมหมดอายุเอง ผู้ประสานเลื่อนเวลา+24ชม.เพื่อทดสอบข้อมูลเก่า/ข้อเสนอหมดอายุได้

ถ้า localStorage เต็ม/ปิด ระบบไม่แจ้งบันทึกสำเร็จและไม่อัปเดต State ถ้าข้อมูลเสียหายหรือผิดรุ่นจะไม่ล้างเงียบ ๆ มีหน้าส่งออกเดิมและยืนยันเริ่มใหม่
ข้อมูลอีกแท็บมี revision ใหม่จะไม่ถูกเขียนทับ ต้องโหลดหน้าใหม่ก่อนทำรายการ

การดับเบิลคลิก index.html แบบ file:// อ่านหน้าและ Navigation ได้ แต่ไม่รับประกัน State ข้ามไฟล์ ต้องใช้ HTTP
หลังเปิด Server ตัดอินเทอร์เน็ตได้ ทรัพยากรหลักอยู่ในโฟลเดอร์ทั้งหมด มือถือยังต้องเชื่อม Wi-Fi/LAN กับคอม
ก่อนใช้จริงต้องพัฒนาฐานข้อมูล/สิทธิ Server การ Sync ระบบคุณภาพ และการตรวจโดยผู้เชี่ยวชาญเพิ่มเติม
