เริ่มได้ภายในไม่กี่คลิก

เลือกบทบาท แล้วเริ่มสถานการณ์

สลับบัญชีสมมติที่มุมขวาบน ทุกบทบาทใช้ข้อมูลเดียวกันใน Browser และ Origin เดียวกัน

ผู้เลี้ยงปลา

  1. บันทึกค่าน้ำ
  2. อ่านผลสองแกนและรับงาน
  3. บันทึกผลติดตาม
  4. เสนอแผนและยืนยันออเดอร์
  5. ชั่งจริงแล้วดูเงินสุทธิ

ร้านอาหาร

  1. เลือกปลาและส่งคำขอ
  2. ยืนยันออเดอร์/ข้อเสนอ
  3. ติดตามรอบส่ง
  4. รับเต็มหรือบางส่วน

ผู้ประสานกลุ่ม

  1. จัดสรรและมอบหมาย
  2. เสนอร้านที่สมัครใจ
  3. ตรวจคุณภาพ รถ เย็น
  4. อนุมัติและส่งมอบ
  5. กระทบยอดและจ่ายในเดโม

เปิดบนคอมพิวเตอร์

แตก ZIP แล้วเปิด Terminal ในโฟลเดอร์ที่มี index.html วิธี Python ต้องติดตั้ง Python3 ถ้าเลือกใช้วิธีนี้

macOS 

python3 -m http.server 8000 --bind 127.0.0.1

Windows 

py -m http.server 8000 --bind 127.0.0.1

เปิด http://localhost:8000/index.html หรือใช้ VS Code Live Server แทนได้ ไม่ต้อง npm

มือถือใน Wi-Fi เดียวกัน

python3 -m http.server 8000 --bind 0.0.0.0

Windows เปลี่ยน python3 เป็น py หา IP ด้วย ipconfig หรือ macOS: System Settings → Wi-Fi → Details → TCP/IP เปิด http://IP-ของคอม:8000/index.html ในมือถือ อนุญาต Firewall เฉพาะเครือข่ายส่วนตัว ไม่ต้องเปิดพอร์ต Router

ข้อมูลแยกตาม Browser และ Origin: localhost กับ IP เป็นคนละชุด มือถือไม่ได้ Sync กับคอม สาธิตสลับบทบาทใน Browser เดียวกันเป็นหลัก

จัดการข้อมูลสาธิต
